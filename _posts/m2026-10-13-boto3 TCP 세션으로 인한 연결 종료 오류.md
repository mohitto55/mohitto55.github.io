## 구현

채팅 접속 시 간헐적 인증 오류 개선

채팅방에 처음 접속할 때 간헐적으로 인증 오류가 발생하고, 재접속하면 정상 동작하는 현상을 확인했다. 조사 결과, 인증 Lambda를 호출하는 과정에서 일시적인 연결 종료 오류가 발생했다.

API Gateway에서 ALB 기반 구조로 전환하면서 애플리케이션이 boto3로 인증 Lambda를 직접 호출하게 됐다. boto3는 연결 풀에 보관한 TCP 연결을 재사용하는데, 유휴 상태에서 종료된 연결을 다시 사용하는 경우 호출이 실패할 수 있다. 이번 현상도 이러한 연결 재사용 과정에서 발생했을 가능성이 있다.

연결 종료 오류는 설정된 타임아웃에 도달하기 전에도 발생할 수 있다. 당시에는 일시적인 통신 오류를 복구하는 재시도가 없어, 해당 오류가 사용자 접속 실패로 이어졌다.

이를 개선하기 위해 인증 호출에서 연결 종료 오류가 발생하면 한 차례 재시도하도록 보완했다. 토큰이나 권한 검증 결과에 따른 접속 거부는 기존대로 유지한다.

관련 테스트와 연결 종료 상황의 복구 동작을 검증했고, dev 환경에 배포해 서비스 정상 기동을 확인했다.
